# Оптимизатор Линейного Раскроя (Linear Cutting Optimizer)

Профессиональное клиентское веб-приложение для расчета оптимального линейного раскроя хлыстового металлопроката, профильных и круглых труб, балок, швеллеров, арматуры и пиломатериалов.

Приложение полностью автономно (Single Page Application на React 19 + TypeScript + Vite + Tailwind CSS). Все расчеты, генерация Excel-файлов, импорт и анализ складов происходят непосредственно в браузере без обращения к внешним серверам и базам данных.

---

## Основные возможности

- **Алгоритм оптимизации**:
  - Подбор вариантов раскроя с высоким КИМ (коэффициент использования материала).
  - Поддержка различных стратегий (по вариантам, минимум отходов, минимум хлыстов, максимум делового остатка, приоритет деловых обрезков со склада).
  - Точный учет ширины пропила (реза) пилы и торцовки кромки хлыста.
  - Автоматический расчет количества стандартных хлыстов (6000 / 12000 мм).
- **Интерактивный анализ и склад («ЕСТЬ»)**:
  - Модальное окно загрузки и анализа файлов склада (.xml, .csv, .txt).
  - Автоматическое распознавание всех материалов/профилей в одном файле.
  - Предварительный просмотр имеющихся обрезков и заготовок для выбранного материала перед загрузкой.
  - Экспорт остатков в новый XML или точечное обновление блока выбранного материала в существующем файле склада.
- **Спецификация заказа («НУЖНО»)**:
  - Добавление позиций, обозначений (марок), длин, количеств и примечаний.
  - Настройка видимости столбцов (марка, примечания).
  - Быстрая вставка строк из буфера обмена (Excel / Таблицы).
- **Наглядные результаты раскроя**:
  - Двухстрочный формат каждой карты раскроя с графической полосой во всю ширину экрана.
  - Сводный блок «ИТОГИ РАСКРОЯ» вверху страницы и легенда цветов/узоров заготовок.
  - Режим для монохромной (Ч/Б) печати с уникальными штриховками заготовок.
  - Мгновенный экспорт результатов в Excel (.xlsx) и печать карт раскроя.
